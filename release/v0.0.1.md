# v0.0.1 — Initial Release

**Nucleus Starterkit** is a domain-agnostic SaaS boilerplate for building two-sided consumer + provider platforms on Laravel 12, Filament 4, and Wave.

Extracted from a production application and generalized through a structured cleanup pass — domain code stripped, vendor namespace renamed to `Nucleus`, and remaining modules rewritten to be industry-neutral.

---

## What's included

**Two-sided architecture**
Three roles out of the box — `admin`, `provider`, and consumer — each with distinct flows and panels. Post-login redirects are config-driven via `config/auth-redirects.php` (first matching role wins, deterministic for multi-role users).

**Dual Filament panels**
- `/admin` — platform operator panel (AdminPanelProvider)
- `/provider` — credentialed-party panel (ProviderPanelProvider)

Both extend a shared `BasePanelProvider`. Branding (name, path, primary color) is soft-configured in `config/panels.php` — forks rebrand without touching PHP.

**Six industry-neutral modules** (`app-modules/`)

| Module | Purpose |
|---|---|
| `providers` | Provider profiles with pluggable credential verifier; swap in your own `CredentialVerifier` implementation via `AppServiceProvider` |
| `onboarding` | 3-step wizard (personal → address → sign); fires `OnboardingCompleted` event for downstream hooks |
| `kyc` | Document upload + admin review + approval email |
| `organisations` | Organisation records with Companies House lookup (UK) |
| `brain` | AI assistant — conversational agents via Laravel AI SDK, Couchbase-backed with DB fallback; agent class map in `config/brain.php` |
| `permit` | Granular RBAC via Spatie Permission, managed in the admin panel |

**Provider profiles**
- `ProviderProfile` model with `provider_type`, `industry`, and a `metadata` JSON column for fork-specific fields
- `NullCredentialVerifier` default (returns `manual_review`); bind your own implementation to go live
- `VerifyProviderCredential` job + `CredentialVerificationResultNotification`

**Key extension points**
- Credential verification: bind `\Nucleus\Providers\Contracts\CredentialVerifier` in `AppServiceProvider`
- Post-onboarding logic: listen to `\Nucleus\Onboarding\Events\OnboardingCompleted`
- AI agents: register role → class in `config/brain.php → agents`; `ExampleAgent` included as a reference
- Extra fields on any profile: use the `metadata` JSON column — no migration needed for fork-specific data

**Activity logging + account lifecycle**
- `ActivityLog::log()` helper; auto-purge after `ACTIVITY_LOG_RETENTION_DAYS` (default 90 days)
- Scheduled account deletion via `php artisan accounts:process-deletions`

## Stack

- Laravel 12
- Filament 4
- Wave (billing/subscription layer)
- Spatie Permission
- Laravel AI SDK (brain module)
- internachi/modular (local Composer packages)
- Pest (testing)

## Quick start

```bash
git clone <repo> my-project && cd my-project
composer install && npm install
cp .env.example .env && php artisan key:generate
php artisan migrate:fresh --seed
composer dev          # server + queue + logs + Vite concurrently
```

Panels: `/admin` · `/provider` · `/onboarding`
